# SHUTTLE STOP — 行き来する布を止めて織る

左右に行き来する布の帯をタップで止めて、下の段に重ねて織り上げる。はみ出たぶんは切り落とされるので、ぴったり止めて細くしないのがこつ。

旧名 ピタオリ（id: pitaori）。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/shuttle-stop/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 布の帯が左右に行き来する。**画面のどこかをタップ**して止めると、下の段の上に重なる。
2. 下の段から**はみ出たぶんは切り落とされる**。次の帯は残った幅で出てくる。
3. **ぴったり**（左端のずれが 4 以下）止めれば幅はそのまま。1 段も重ならないか、幅が 6 未満になったら終わり。何段織れたかが記録。

- PC では Space / Enter でも止められる（タイトルと結果では「はじめる」「もう一度」）。
- 帯は段を重ねるほど速くなる。世界の幅は 360 に固定しているので、どの画面でも難しさは同じ。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

一度開けば、オフラインでも遊べます。

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 帯の動き・切り落とし・ぴったり・終わり・記録のテスト（フレームワークなし）
```

| ファイル | 中身 |
|---|---|
| `logic.js` | 数値（調整つまみ）・帯の動き・止めたときの判定・画面の追いかけ・記録の読み書き（DOM に触らない） |
| `main.js` | 画面の切り替え・操作・描画 |
| `test.mjs` | `logic.js` のテスト |

- 段の高さ・土台の幅・速さの式・ぴったりの幅などは `logic.js` の先頭にまとめてある。
- 記録は端末内の `localStorage` の `shuttle-stop.best`（`{ v: 1, rows, perfect }`）。旧名「ピタオリ」時代の `pitaori.best` があれば引き継ぐ。
